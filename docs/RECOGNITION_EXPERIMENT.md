# Эксперимент: выбор распознавателя речи

Начат 16.10.2026. Цель — по результатам выбрать распознаватель для навыка `speak` (решение Р23 принимает владелец продукта). В этом файле только агрегаты: ни звука, ни текстов отдельных ответов (они лежат локально в `E:\dev\mana-lab\`, вне репозитория).

## Как устроено

- **Набор**: 77 пунктов из колод «Дарси 01» и test-speak; ожидаемый вердикт каждого пункта вычислен функцией приложения `checkSpoken(эталон, [что сказано])` (Р22, с уточнением п. 7 от 16.10.2026).

  | Категория | Пунктов | Ожидаем верно / почти / неверно |
  |---|---|---|
  | верное, обычное | 20 | 20 / 0 / 0 |
  | короткое слово | 15 | 15 / 0 / 0 |
  | ошибка: другой артикль | 7 | 0 / 0 / 7 |
  | ошибка: другое слово | 7 | 0 / 1 / 6 |
  | ошибка: пропущено слово | 5 | 0 / 2 / 3 |
  | ошибка: лишнее слово | 3 | 0 / 3 / 0 |
  | похожее слово (другое слово) | 10 | 0 / 0 / 10 |
  | верное, небрежно | 5 | 5 / 0 / 0 |
  | повтор эталона | 5 | 5 / 0 / 0 |

- **Запись**: владелец продукта, Android 10, Chrome 155, страница `#/lab/record`, 16.10.2026. Звук — `MediaRecorder` (webm/opus), для сервисов перекодирован в WAV 16 кГц моно в браузере. Средняя длина записи 2,3 с, всего ≈ 3 мин.
- **Chrome (база)** — второй проход: тот же пункт сказан ещё раз, слушает только Web Speech (одновременно с `MediaRecorder` на Android работать ненадёжно). Значит, у Chrome **другой дубль** того же текста. Результат есть для 74 пунктов из 77 (три пункта во втором проходе не записаны).
  - Проба одновременной работы на телефоне: на всех 77 пунктах, где Chrome запускался вместе с `MediaRecorder`, он не вернул ни результата, ни ошибки — **одновременно не работает** (подтверждает Chromium 41403126).
- **Сервисы и варианты** (Cloudflare Workers AI, REST, язык `fr`):
  - Whisper large-v3-turbo — без подсказок; с `initial_prompt` = словарь колод (те же слова, что приложение отдало бы `biasPhrases`: все слова всех записей колод, не ожидаемый ответ); дополнительно — с `vad_filter` (фильтр тишины, против галлюцинаций; в плане не было, добавлено как дешёвый вариант).
  - Deepgram Nova-3 — без подсказок, `mip_opt_out=true` (запись не идёт в программу улучшения моделей Deepgram). **Вариант со словарём невозможен**: Workers AI отвечает на `keyterm` «The selected Nova-3 model does not support keyterm prompting» (для `fr` и `multi`), а `keywords` для Nova-3 не поддерживается.
  - Google Speech-to-Text V2 — позже, на тех же записях.
- **Пробы тишины и шума** (для галлюцинаций): 2 с тишины, 2 с тихого белого шума, 2 с фона комнаты (склеено из пауз перед речью в записях). Ожидается пустой ответ.

## Метрики

По каждому сервису и варианту, по категориям:

- **засчитано неверных** (главная): ожидали «почти» или «неверно», получили «верно»;
- **отвергнуто верных**: ожидали «верно», получили «почти» или «неверно» (пустой ответ — тоже «неверно»);
- таблица «ожидали / получили» (верно / почти / неверно);
- пустые ответы;
- совпадение распознанного текста со сказанным (после той же нормализации, что в сверке) — чтобы отличить ошибку распознавателя от ошибки нашей сверки;
- **подсказка «протекла»**: в ответе есть слово из словаря колод, которого не было в сказанном (считается для всех вариантов, чтобы видеть, сколько даёт сама подсказка);
- **галлюцинации**: непустой ответ на пробе тишины / шума; ответ на записи, у которого нет ни одного общего слова ни со сказанным, ни с эталоном;
- время ответа сервиса (медиана, 90-й процентиль). **Это нижняя граница**: в приложении добавятся отправка звука из сети телефона и ожидание конца речи (определение, что человек замолчал);
- стоимость при 1500 мин звука в месяц.

## Правило выбора (зафиксировано до прогона)

Сравнение с Chrome — на пунктах, где есть результат Chrome (74 из 77). Кандидат (сервис + вариант) **лучше Chrome**, если выполнены все условия:

1. **Засчитано неверных не больше, чем у Chrome** (по всем пунктам с ожиданием «почти» / «неверно»).
2. **Короткие слова отвергаются заметно реже**: отвергнутых верных в категории «короткое слово» не больше половины от Chrome **и** хотя бы на 3 меньше. Если Chrome отвергает 2 коротких слова или меньше, заметного преимущества быть не может — условие не выполнено.
3. **В остальном не хуже**: отвергнутых верных во всех категориях с ожиданием «верно» (обычные, короткие, небрежно, повтор) не больше, чем у Chrome.

Если условиям отвечают несколько кандидатов: меньше засчитанных неверных → меньше отвергнутых коротких → дешевле.

Порог «на 3 меньше» — практический, а не статистический: на 14–15 коротких словах разница в 1–2 пункта может быть случайной, а при одном говорящем и одном дубле любой вывод предварительный. Правило фиксирует, что считаем успехом, до того как увидели результаты.
