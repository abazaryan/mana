## Метрики

По каждому сервису и варианту, по категориям:

- **засчитано неверных** (главная): ожидали «почти» или «неверно», получили «верно»;
- **отвергнуто верных**: ожидали «верно», получили «почти» или «неверно» (пустой ответ — тоже «неверно»);
- таблица «ожидали / получили» (верно / почти / неверно);
- пустые ответы;
- совпадение распознанного текста со сказанным (после той же нормализации, что в сверке) — чтобы отличить ошибку распознавателя от ошибки нашей сверки;
- **подсказка «протекла»**: в ответе есть слово из словаря колод, которого не было в сказанном (считается для всех вариантов, чтобы видеть, сколько даёт сама подсказка);
- **галлюцинации**: непустой ответ на пробе тишины / шума; ответ на записи, у которого нет ни одного общего слова ни со сказанным, ни с эталоном;
- время ответа сервиса (медиана, 90-й процентиль). **Это нижняя граница**: в приложении добавятся отправка звука из сети телефона и ожидание конца речи (определение, что человек замолчал);
- стоимость при 1500 мин звука в месяц.

## Правило выбора (зафиксировано до прогона)

Сравнение с Chrome — на пунктах, где есть результат Chrome (74 из 77). Кандидат (сервис + вариант) **лучше Chrome**, если выполнены все условия:

1. **Засчитано неверных не больше, чем у Chrome** (по всем пунктам с ожиданием «почти» / «неверно»).
2. **Короткие слова отвергаются заметно реже**: отвергнутых верных в категории «короткое слово» не больше половины от Chrome **и** хотя бы на 3 меньше. Если Chrome отвергает 2 коротких слова или меньше, заметного преимущества быть не может — условие не выполнено.
3. **В остальном не хуже**: отвергнутых верных во всех категориях с ожиданием «верно» (обычные, короткие, небрежно, повтор) не больше, чем у Chrome.

Если условиям отвечают несколько кандидатов: меньше засчитанных неверных → меньше отвергнутых коротких → дешевле.

Порог «на 3 меньше» — практический, а не статистический: на 14–15 коротких словах разница в 1–2 пункта может быть случайной, а при одном говорящем и одном дубле любой вывод предварительный. Правило фиксирует, что считаем успехом, до того как увидели результаты.

## Результаты

Прогон 16.10.2026, `node tools/lab/compare.ts` (ответы сервисов кэшируются локально; повторный прогон даёт те же числа бесплатно). Стоимость самого прогона — меньше $0,01.

**Итог по правилу (предварительный — база Chrome завышена, см. ниже): ни один вариант не лучше Chrome.** Все четыре не выполнили ни одного из трёх условий: засчитывают неверных в 5–6 раз чаще (5–6 из 31 против 1), отвергают верных чаще (3–4 из 43 против 0), на коротких словах выигрывать было не у чего (Chrome отверг 0 из 14).

### Что видно по ответам (обобщённо, без текстов пунктов)

- **Главный источник ложных «верно» — «исправление» ошибок ученика.** Неверный артикль (не тот род) облачные распознаватели в 3–4 случаях из 7 записывают грамматически правильным артиклем — то есть ошибка ученика превращается в «верно». У Chrome — 1 из 7. Похожее слово (другое слово, близкое по звучанию к эталону) Deepgram в 3 из 9 случаев записал словом эталона, Whisper со словарём — в 2, Whisper без подсказки — в 1, Chrome — ни разу. Эту ошибку не исправить на стороне сверки: распознаватель возвращает текст, неотличимый от верного ответа.
- **Whisper пишет одиночное «un» цифрой «1»**, а наша сверка приравнивает «1» к «un» (Р5) — поэтому похожее слово в этой позиции засчиталось.
- **Отвергнутые верные** у облачных сервисов — непривычная для них речь: имена и прилагательные национальности, отдельные короткие слова, число из трёх слов, разобранное как другие слова. У Whisper без фильтра это, кроме того, ответы вида «латиница наугад» на коротком слове.
- **Словарь колод (initial_prompt) у Whisper почти ничего не меняет**: точность текста немного выше (55 против 51 совпадения со сказанным), но засчитанных неверных на 1 больше — один раз подсказка подставила слово из словаря вместо похожего (именно то, о чём было опасение). На повторе эталона подсказка однажды испортила ответ.
- **Галлюцинации Whisper на тишине**: без фильтра на всех трёх пробах (тишина, шум, фон) Whisper вернул текст — подпись субтитров, а на шуме — «Merci.», то есть слово из колоды: на карточке с этим словом молчание засчиталось бы как верный ответ. С `vad_filter` — 0 из 3. Deepgram на пробах всегда пуст.
- **Время ответа** (нижняя граница, с ноутбука): Deepgram — 0,7 с в медиане, 1,0 с в 90 %; Whisper — 1,5 с в медиане, но до 4,5–5 с в 90 % (видимо, очередь на стороне Cloudflare).

### Что можно сказать без честной базы Chrome

Новый проход Chrome (первая попытка) владелец продукта решил не делать (16.10.2026): решение Р23 — по имеющимся данным. Правило выбора поэтому применить честно нельзя; ниже — только то, что от базы Chrome не зависит.

- **Облачные сервисы с одного дубля, без повторов**: ложных «верно» 5–6 из 31, из них неверный артикль — 3–4 из 7. Это прямо противоречит принципу Р22.1 (ложное «верно» хуже ложного «Снова») и цели подсказки формы: ошибку рода, которую карточка проверяет, распознаватель «исправляет» до сверки. Подсказкой (словарь) это не лечится, а у Deepgram на французском словаря нет вовсе.
- **Короткие слова облако распознаёт хорошо**: 13 из 14 с первого дубля у всех четырёх вариантов. Это единственное явное преимущество облака — и ровно та проблема, с которой начинался эксперимент. Насколько плохо Chrome справляется с первой попытки, этот эксперимент не показал; по журналам приложения 15.10.2026 «un / deux / trois» приходили пустыми, по странице записи (с повторами) — нет.
- **Цена облака — не только деньги**: нужен свой адаптер (запись звука, определение конца речи), серверный прокси на Cloudflare с ключом, передача звука ещё одному сервису; к ответу добавляется ≈ 0,7 с (Deepgram) или 1,5–5 с (Whisper) плюс сеть телефона. Whisper без фильтра тишины выдаёт текст на молчании. Одновременно с Chrome облачный распознаватель на Android работать не может (запись и Web Speech конфликтуют), так что «Chrome + облако на тот же звук» невозможно — только по очереди, с повторной речью.
- **Варианты решения**: (а) остаться на Chrome Web Speech, ввод текстом после трёх неудач остаётся, а частоту неудач на коротких словах измерить по журналу приложения (там уже пишутся коды ошибок и повторы); (б) Chrome основной, облако — только для повторной попытки после пустого ответа Chrome (стоит сервера и адаптера, ложные «верно» облака переходят и в эту попытку); (в) перейти на облако целиком — больше ложных «верно».

### Оговорки

- **База Chrome завышена.** У Chrome другой дубль, и во втором проходе владелец продукта иногда нажимал «Ещё раз», когда Chrome слышал не то (подтверждено 16.10.2026); в результат попадала последняя попытка, сколько было повторов — не записано. Значит, цифры Chrome (1 ложное «верно», 0 отвергнутых) — лучше, чем было бы с первой попытки, причём по обеим метрикам: повтор мог исправить и ложное «верно», и отказ. **Сравнение с Chrome пока недействительно**; абсолютные цифры облачных сервисов (5–6 ложных «верно» из 31, галлюцинации Whisper на тишине) от этого не зависят. Для честной базы — новый проход Chrome, где засчитывается первая попытка, а повторы только записываются в журнал.
- **Chrome здесь распознал все 14 коротких слов**, хотя в журналах приложения 15.10.2026 «un», «deux», «trois» приходили пустыми (`nomatch` / `no-result`). Возможные причины: повторы (см. выше); на странице записи человек нажимал кнопку и говорил после неё, а в приложении микрофон включается сам и начало слова может попадать на запуск распознавателя; другая обстановка. Это не проверено — но значит, что проблема коротких слов может быть не в распознавателе, а в моменте старта.
- Один говорящий, один дубль на пункт, 74 пункта: разница в 1–2 пункта может быть случайной. Разрыв по ложным «верно» (1 против 5–6) — уже не 1–2 пункта, но всё равно на одном человеке.
- Параметры Whisper не подбирались (кроме языка, словаря и фильтра тишины); Deepgram — с параметрами по умолчанию, словарь для французского в Workers AI недоступен.
- Google Speech-to-Text V2 пока не проверялся.
