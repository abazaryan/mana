# Таджикские строки на утверждение (21.10.2026)

Новые и изменённые строки интерфейса: часть П (личные колоды без сервера, голос браузера — Р33 пп. 14–16) с поправками владельца 21.10.2026 и правка «Таркиби маҷмӯа» → «Омӯзбаргҳо». Значения взяты из кода (`src/ui/strings.ts`, `src/core/languages.ts`) скриптом. Пока строки не утверждены, изменения не отправляются в `main`.

Уже учтено (решения владельца 21.10.2026): «овоз» отклонён — голос и звук — «садо» («файли садо» — звук колоды, «садои мурургар» — голос браузера, «Санҷиши садо» — проверка); «ИИ» → «ҳуши маснӯӣ» (кратко «ҳушвора» — только в тесных местах рядом с полной формой; не понадобилась). Слова и кандидаты — `docs/GLOSSARY_TG.md`, раздел «На утверждение: часть П».

Шаблон задания для ИИ (копируется кнопкой «Нусхаи дастур», таджикский интерфейс; `src/ui/deckPrompt.ts`):

```text
СУПОРИШ (ЗАДАНИЕ)
Забони омӯзиш (язык): fr-FR
Забонҳои маъно (языки значений): tg
Садо (звук): нест
id ва номи маҷмӯа (id и название): my-fr-<мавзӯъ>-01; ном — …
Мӯҳтаво (содержание): <мавзӯъ, вожаҳо ё матни дарс>
Маҷмӯаҳои насбшуда (уже установленные колоды): <«Нусхаи омӯзбаргҳои насбшуда»-ро ин ҷо гузоред>
```

Слова шаблона: «супориш» (задание) — новое, на проверку; «забони омӯзиш», «забонҳои маъно», «мавзӯъ», «мӯҳтаво» — новые; «садо», «маҷмӯа», «омӯзбарг» — из глоссария. В скобках — русские названия полей для ИИ.
