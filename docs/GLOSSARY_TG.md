# Глоссарий таджикских терминов интерфейса Mana (Моно)

Утверждено владельцем продукта 12.10.2026. Это источник правды для таджикских строк в `src/ui/strings.ts` и для новых строк на следующих этапах. Полная таблица строк — `docs/I18N_TG.md` (генерируется из кода).

## Принцип

- «Таджикский» в Mana — это персидский язык Ирана, адаптированный к таджикской фонетике и записанный таджикской кириллицей.
- Приоритет источников при выборе слова: Иран → Афганистан → Таджикистан. Русизмов избегаем.
- Арабизмы допустимы, но если есть точный и понятный персидский термин — предпочитаем его.
- Нужен термин, передающий смысл понятия в приложении, а не дословный перевод с русского или английского. Распространённость слова доказывает узнаваемость, а не качество: дословные кальки (например, «дасте» для deck в персидском Anki) не наследуются автоматически.
- Проверочный критерий: термин понятен пользователю из Таджикистана без объяснений или с первого раза по контексту.
- Грамматика: решается по каждому случаю. Ориентир — формы, общие для иранской и таджикской грамматики (простое настоящее, отглагольные существительные, вежливое «кунем?»); избегать того, что есть только у одной стороны (таджикский длительный вид с «истодан», иранское разговорное «дорад + глагол»).
- Форма императива (решение владельца 17.10.2026, Р26): «бигӯед» — с «би-»; «хонед», «нависед» — без.
- Одна инструкция на шаге (Р26): под кругом микрофона или внутри поля (placeholder), без заголовка-дубля.
- Стиль кнопок: краткая форма без «кардан», где слово самодостаточно (Бастан · Лағв · Захира · Насб · Бозгашт); «кардан» — только в длинных подписях-предложениях.

## Два слова с разделённым значением

- **сабт** (ثبت) — только *запись журнала* (строка лога): «Дар файл сабтҳо: {n}». Фарҳангистон закрепил ثبت за ведением журнала. Для записи колоды не используется.
- **маълумот** (معلومات) — только *информация, сведения*: «мурургар … маълумот намедиҳад». Для *данных* (data) — **додаҳо** (داده‌ها).

## Термины

Степень уверенности: В — высокая, С — средняя. Строка «Проверить на семье» — термин принят по смыслу и этимологии, но его узнаваемость в Таджикистане не подтверждена; проверить на первом же пользователе.

### Навыки

| Ключ | tg | Персидское письмо |
| --- | --- | --- |
| listen | гӯш додан | گوش دادن |
| speak | гуфтан | گفتن |
| write | навиштан | نوشتن |

Понятие «навык» (тип карточки: `listen`, `speak`, `write`) — **маҳорат** (مهارت; Иран — термин языковой методики, «чахор маҳорат»; Тадж. — «маҳорат»). Утверждено владельцем 19.10.2026; на экран пока не выводится. Отклонено: малака (в Иране ملکه — другое значение).

Набор: гӯш додан · гуфтан · навиштан. *(Изменено 16.10.2026: `listen` был «шунидан».)* «Шунидан» закреплено за сообщениями распознавателя («Нодуруст шунид», «вожаи дигар шунида шуд», «Чизе шунида нашуд»). Отклонены: шунидорӣ (شنیداری — термин аудирования в Иране, но тогда для остальных навыков нужны «гуфторӣ» / «навишторӣ»), шунавоӣ (شنوایی — слух как чувство).

### Занятия

## Коды языков

Коды языков — BCP 47 (RFC 5646).

- **Язык интерфейса и значений** (`meaning`, `hint`, `note`, названия тегов, `app.name` и т. п.) — только ISO 639-1: `tg`, `ru`, `en`.
- **Изучаемый язык колоды** (`language`) — с регионом, например `fr-FR`: он задаёт локаль распознавания и озвучки.
- Не использовать `tj`, `tgk`, `tg-TJ` для интерфейса и значений. Валидатор принимает такие ключи с предупреждением, приложение их не показывает.

## Что проверить на пользователях

1. «омӯзбарг» — понятно ли «Омӯзбаргҳо: 30» без подсказки.
2. «мурургар» — понятно ли «танҳо дар ҳамин мурургар».
3. «захирагоҳ», «ҳамгомсозӣ», «барӯзрасонӣ», «дарунрезӣ», «бозёбӣ» — читаются ли по корням с первого раза.
4. Занятия (14.10.2026): «тамрин», «давр», «ошноӣ», «Баъдӣ», «Гузаштан», «Нодуруст шунид», «бозшиносии гуфтор» — понятны ли без подсказки.

Если термин не прошёл, запасной вариант указан в примечании; замена делается в глоссарии и в `strings.ts` одновременно.
