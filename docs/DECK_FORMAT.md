# Формат колоды «Слуха» (`sluh-deck`, версия 1)

Основано на решениях Р2 и Р3 (`docs/DECISIONS.md`). Машинная схема: [`src/core/sluh-deck.schema.json`](../src/core/sluh-deck.schema.json) (JSON Schema 2020-12). Валидатор: [`src/core/deckFormat.ts`](../src/core/deckFormat.ts). При расхождении этого описания и валидатора прав валидатор — он же работает в приложении.

## Архив

Колода — ZIP-архив:

```
fr-lesson-01.zip
├── deck.json
└── audio/
    ├── bonjour.mp3
    ├── le-nom.mp3
    └── …
```

- `deck.json` лежит **в корне** архива (не внутри папки). Кодировка UTF-8.
- Аудио — в папке `audio/` (можно с подпапками). Форматы: `mp3`, `wav`, `ogg`, `opus`, `m4a`, `webm`; расширение строчными буквами.
- Другие файлы пропускаются (валидатор предупреждает о них). Служебные файлы macOS и Windows (`__MACOSX/`, `.DS_Store`, `Thumbs.db`) не учитываются.

## `deck.json`

```json
{
  "format": "sluh-deck",
  "version": 1,
  "id": "fr-lesson-01",
  "title": "Фаронсавӣ · Дарси 01",
  "entries": [
    {
      "id": "le-nom",
      "fr": "le nom",
      "ipa": "lə nɔ̃",
      "meaning": { "tg": "насаб", "ru": "фамилия", "en": "surname" },
      "audio": "audio/le-nom.mp3",
      "gender": "m",
      "skills": ["listen", "speak", "write"]
    }
  ]
}
```

### Колода

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | да | Всегда `"sluh-deck"`. |
| `version` | да | Версия формата, сейчас `1`. Колоду с версией новее приложение не примет и попросит обновиться. |
| `id` | да | Устойчивый идентификатор колоды (правила — ниже). |
| `title` | да | Название колоды для показа. |
| `entries` | да | Список записей, хотя бы одна. |

### Запись

Одна запись = одна учебная единица (Unit). Каждый навык из `skills` — отдельная карточка со своим состоянием FSRS (Unit × Skill).

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Устойчивый идентификатор записи, уникальный внутри колоды. |
| `fr` | да | Французский текст — **единственный** правильный ответ (Р3). Другая формулировка — отдельная запись. |
| `ipa` | нет (предупреждение, если нет) | Произношение в IPA **без** скобок `[ ]` и косых `/ /`: `"lə nɔ̃"`. |
| `meaning` | да | Значение на одном или нескольких языках: ключи `tg`, `ru`, `en`. Хотя бы один. Какой показывать, выбирает пользователь в настройках; если выбранного нет, показывается другой имеющийся. |
| `audio` | нет | Путь к файлу внутри архива: `"audio/le-nom.mp3"`. Без аудио приложение использует встроенный синтез речи (запасной вариант). |
| `gender` | нет | Род существительного: `"m"` или `"f"`. Если рода нет (глагол, фраза, число), поле не пишется. |
| `skills` | да | Навыки (типы карточек), хотя бы один, без повторов: `listen` — услышать и повторить вслух; `speak` — увидеть значение и сказать по-французски; `write` — увидеть значение и написать. |

Все тексты — простой текст: без HTML, `&nbsp;` и разметки Anki (`[sound:…]`).

### Идентификаторы

- Строчные латинские буквы, цифры, `-`, `_`, `.`; до 64 символов; первый символ — буква или цифра. Пример: `je-m-appelle`.
- **id не меняется никогда**, даже если исправлен текст записи. По id повторный импорт исправленной колоды обновляет содержимое и сохраняет прогресс (Р2). Новый id = новая запись с нуля.
- Удобно делать id из французского текста при создании записи (без акцентов, пробелы и апострофы → `-`), но потом это просто метка.

## Проверка

Валидатор собирает **все** ошибки сразу и пишет их по-русски, с номером и id записи, например:

```
ОШИБКА: Запись 7 (id «le-nom»): IPA пишется без скобок [ ] и косых / / — приложение добавит их само. Сейчас: «[lə nɔ̃]».
ОШИБКА: Запись 12: файла «audio/je-suis.mp3» нет в архиве.
Предупреждение: Значение на ru есть не у всех записей: не хватает у 3 из 30. Для них приложение покажет другой язык.
```

**Ошибки** (колода не принимается): неверный JSON; нет `deck.json` или он в папке; не тот `format`; неподдерживаемая `version`; нет обязательного поля или у него не тот тип; пустой текст; HTML в тексте; неправильный id; одинаковые id записей; неизвестный язык в `meaning`; неизвестный или повторённый навык; `gender` не `m`/`f`; путь аудио не в `audio/`, с `\` или `..`, неподдерживаемое расширение; аудиофайла нет в архиве (с подсказкой, если не совпадает только регистр букв).

**Предупреждения** (колода принимается): нет IPA; неизвестное поле (будет пропущено); одинаковый французский текст у двух записей; один аудиофайл у двух записей; значение на каком-то языке есть не у всех записей; пробелы в начале или конце текста; аудиофайл не используется; лишние файлы в архиве.

Проверить колоду на компьютере до загрузки:

```bash
npm run deck:check -- путь/к/колоде.zip
```

## Как собрать архив

Заархивировать **содержимое** папки (файл `deck.json` и папку `audio`), а не саму папку. В Windows: выделить `deck.json` и `audio` → правая кнопка → «Сжать в ZIP-файл».

## Изменения формата

Несовместимые изменения повышают `version`. Новые необязательные поля могут появиться без смены версии: старое приложение их пропустит с предупреждением.
