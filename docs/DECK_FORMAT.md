# Формат колоды «Маны» (`mana-deck`, версия 1)

Основано на решениях Р2, Р3, Р13–Р16 (`docs/DECISIONS.md`). Машинная схема: [`src/core/mana-deck.schema.json`](../src/core/mana-deck.schema.json) (JSON Schema 2020-12). Валидатор: [`src/core/deckFormat.ts`](../src/core/deckFormat.ts), языковые пакеты: [`src/core/languages.ts`](../src/core/languages.ts). При расхождении этого описания и валидатора прав валидатор — он же работает в приложении.

## Архив

Колода — ZIP-архив:

```
Фаронсавӣ · Дарси 01.zip
├── deck.json
└── audio/
    ├── bonjour.mp3
    ├── le-nom.mp3
    └── …
```

- **Название колоды — имя ZIP-файла без расширения**, на любом языке: «Фаронсавӣ · Дарси 01.zip» → «Фаронсавӣ · Дарси 01». В `deck.json` названия нет. Прогресс привязан к `id` колоды, а не к названию: переименованный файл — та же колода, при импорте новой редакции название обновится по имени нового файла.
- `deck.json` лежит **в корне** архива (не внутри папки). Кодировка UTF-8.
- Аудио — в папке `audio/` (можно с подпапками). Форматы: `mp3` или `wav`, расширение строчными буквами. MP3 в 5–10 раз меньше WAV — лучше для телефона.
- Архив больше **20 МБ** валидатор принимает, но предупреждает: его долго скачивать на телефон. Для примера: урок 1 (30 записей, WAV) весит 1,3 МБ.
- Другие файлы пропускаются (валидатор предупреждает о них). Служебные файлы macOS и Windows (`__MACOSX/`, `.DS_Store`, `Thumbs.db`) не учитываются.

## `deck.json`

```json
{
  "format": "mana-deck",
  "version": 1,
  "id": "fr-lesson-01",
  "revision": 1,
  "language": "fr-FR",
  "tags": {
    "word": { "tg": "вожа", "ru": "слово", "en": "word" },
    "number": { "tg": "адад", "ru": "число", "en": "number" }
  },
  "entries": [
    {
      "id": "le-nom",
      "text": "le nom",
      "ipa": "lə nɔ̃",
      "meaning": { "tg": "насаб", "ru": "фамилия", "en": "surname" },
      "hint": { "ru": "в анкете" },
      "note": { "ru": "Не путать с le prénom — «имя»." },
      "audio": "audio/le-nom.mp3",
      "gender": "m",
      "form": { "determiner": "definite" },
      "tags": ["word"],
      "skills": ["listen", "speak", "write"]
    },
    {
      "id": "un-nom",
      "text": "un nom",
      "ipa": "ɛ̃ nɔ̃",
      "meaning": { "tg": "насаб", "ru": "фамилия", "en": "surname" },
      "audio": "audio/un-nom.mp3",
      "gender": "m",
      "form": { "determiner": "indefinite" },
      "tags": ["word"],
      "skills": ["listen", "speak", "write"]
    },
    {
      "id": "ravi",
      "text": "ravi",
      "ipa": "ʁa.vi",
      "meaning": { "tg": "хурсанд", "ru": "рад", "en": "glad" },
      "audio": "audio/ravi.mp3",
      "form": { "gender": "m" },
      "tags": ["word"],
      "skills": ["listen", "speak", "write"]
    },
    {
      "id": "ravie",
      "text": "ravie",
      "ipa": "ʁa.vi",
      "meaning": { "tg": "хурсанд", "ru": "рада", "en": "glad" },
      "audio": "audio/ravie.mp3",
      "form": { "gender": "f" },
      "tags": ["word"],
      "skills": ["write"]
    }
  ]
}
```

### Колода

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | да | Всегда `"mana-deck"`. Прежний `"sluh-deck"` (рабочее название «Слух») валидатор принимает с предупреждением. |
| `version` | да | Версия формата, сейчас `1`. Колоду с версией новее приложение не примет и попросит обновиться. |
| `id` | да | Устойчивый идентификатор колоды (правила — ниже). |
| `revision` | да | Номер редакции колоды: целое от 1, увеличивается при каждом изменении колоды (см. «Обновление колоды»). |
| `language` | да | Изучаемый язык, код BCP-47 с регионом: `fr-FR`, `en-GB`, `de-DE`, `lb-LU` (подробно — «Коды языков»). Приложение принимает только языки, для которых есть языковой пакет; сейчас — французский (`fr`, любой регион). |
| `tags` | нет | Словарь тегов: код → название на языках интерфейса (`tg`, `ru`, `en`, хотя бы на одном). Записи ссылаются на коды. Приложение показывает название на языке интерфейса, а если его нет — любое имеющееся. |
| `entries` | да | Список записей, хотя бы одна. **Порядок записей — порядок знакомства** с новыми записями. |

### Запись

Одна запись = одна учебная единица (Unit). Каждый навык из `skills` — отдельная карточка со своим состоянием FSRS (Unit × Skill).

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Устойчивый идентификатор записи, уникальный внутри колоды. |
| `text` | да | Текст на изучаемом языке — **единственный** правильный ответ (Р3). Другая формулировка или другая форма — отдельная запись. Скобки и «/» для нескольких ответов (`ravi(e)`, `A / B`, `le/la …`) не используются: валидатор предупреждает. |
| `ipa` | нет (предупреждение, если нет) | Произношение в IPA **без** скобок `[ ]` и косых `/ /`: `"lə nɔ̃"`. |
| `meaning` | да | Значение на языках интерфейса (`tg`, `ru`, `en`), хотя бы на одном. Какой показывать, выбирает пользователь; если выбранного нет, показывается другой имеющийся. |
| `hint` | нет | Подсказка, видна **до** ответа (уточняет, какой ответ нужен): `{"ru": "вежливо"}`. На языках интерфейса. |
| `note` | нет | Заметка, видна **после** ответа (пояснение, исключение): `{"ru": "Связывание: vous‿êtes"}`. На языках интерфейса. |
| `audio` | нет | Путь к файлу внутри архива: `"audio/le-nom.mp3"`. Без аудио приложение использует встроенный синтез речи (запасной вариант). |
| `gender` | нет | Род самого слова (существительного): `"m"`, `"f"` или `"n"`. Должен быть в языке колоды: во французском только `m` и `f`. Показывается **только при знакомстве**, не при вспоминании. У глаголов, фраз, чисел поля нет. |
| `form` | нет | Какая форма нужна в ответе (Р16). Объект, хотя бы одно поле из трёх; приложение показывает подсказки **до ответа** на языке интерфейса. **Каждая форма — отдельная запись** («le nom» и «un nom»; «ravi» и «ravie»). Подробно — ниже. |
| `tags` | нет | Коды тегов из словаря `tags` колоды, например `["word"]`. Код — по правилам id (ниже). Рекомендуемые коды: `word` (отдельное слово), `phrase` (фраза, предложение), `number` (число); можно добавлять свои (тема урока и т. п.). Код без описания в словаре валидатор принимает с предупреждением, приложение покажет сам код. |
| `skills` | да | Навыки (типы карточек), хотя бы один, без повторов: `listen` — услышать и повторить вслух; `speak` — увидеть значение и сказать на изучаемом языке; `write` — увидеть значение и написать. Карточка `listen` выдаётся только записи с `audio` (Р25): встроенный голос браузера произношению не учит. |

Все тексты — простой текст: без HTML, `&nbsp;` и разметки Anki (`[sound:…]`).

### Форма ответа (`form`)

| Поле | Значения | Подсказка (tg / ru / en) | Когда |
|---|---|---|---|
| `determiner` | `"definite"` — определённая (fr: le, la, l', les); `"indefinite"` — неопределённая (un, une, des) | «муай.» / «опред.» / «def.»; «номуай.» / «неопред.» / «indef.» | существительное с артиклем |
| `gender` | `"m"`, `"f"`, `"n"` (только роды языка колоды) | «музак.» / «м. р.» / «m.»; «муан.» / «ж. р.» / «f.»; «хунсо» / «ср. р.» / «n.» | формы, которые различаются родом: `ravi` / `ravie`, `il est prêt` / `elle est prête` |
| `number` | `"singular"`, `"plural"` | «танҳ.» / «ед. ч.» / «sg.»; «ҷамъ» / «мн. ч.» / «pl.» | формы, которые различаются числом, если значение этого не показывает |

`form.gender` — род нужного ответа, а `gender` записи — род самого слова. У существительного обычно хватает `gender` и `form.determiner`; `form.gender` нужен, когда одно значение даёт ответы разного рода. Подсказки идут в порядке determiner, gender, number. Неизвестное поле внутри `form` пропускается с предупреждением.

**Навыки у форм (Р16, Р25).** Формы, которые звучат одинаково (`ravi` / `ravie`, `ami` / `amie`), голосом не различить: навыки `speak` и `listen` — только у одной записи (первой), `write` — у обеих. Формы, которые звучат по-разному (`petit` / `petite`, `voisin` / `voisine`), — `speak` и `listen` у обеих. Решает автор колоды; в примере выше у `ravie` только `write`. Проверка колоды предупреждает, если у двух записей, совпадающих по звучанию (сверка голоса засчитывает каждую вместо другой), есть `speak` или `listen`.

### Идентификаторы

Правила одни для id колоды, id записей и кодов тегов:

- Строчные латинские буквы, цифры, `-`, `_`, `.`; до 64 символов; первый символ — буква или цифра. Пример: `je-m-appelle`.
- **id не меняется никогда**, даже если исправлен текст записи. По id повторный импорт исправленной колоды обновляет содержимое и сохраняет прогресс (Р2). Новый id = новая запись с нуля.
- Удобно делать id из текста при создании записи (без акцентов, пробелы и апострофы → `-`), но потом это просто метка.
- **id колоды** строится как `<язык>-<тема>-<номер>`: `fr-lesson-01`, `fr-family-01`, `de-numbers-01`. Он должен быть уникальным среди всех колод: две разные колоды с одним id приложение считает редакциями одной колоды. Если у установленной колоды с тем же id записи почти не совпадают с новым файлом (общих id меньше половины от меньшей колоды) или другой изучаемый язык, приложение предупреждает и спрашивает, устанавливать ли.

## Обновление колоды

- Исправили колоду — увеличьте `revision` на 1; `id` колоды и записей не меняйте. Имя файла можно поменять — название колоды обновится.
- Записи, которых нет в новой редакции, приложение скрывает, их прогресс не удаляется (вернёте запись с тем же id — прогресс вернётся).
- Если загружается редакция старее уже установленной, приложение предупреждает; если та же — спрашивает «Переустановить?». В обоих случаях журнал и прогресс не меняются.
- Как это устроено в приложении: `docs/DATA_MODEL.md`, раздел «Импорт колоды».

## Языки

Всё, что зависит от изучаемого языка (нормализация текста, сверка по звучанию, числа, ряд букв своей клавиатуры, какие есть роды), — в языковом пакете (Р13). Пакет выбирается по основной части кода: `fr-FR` и `fr-CA` → французский. Если регион не указан (`"fr"`), распознавание и озвучка идут с `fr-FR`. Сейчас есть только французский; перед первой колодой на новом языке нужно проверить распознавание и озвучку на устройствах (особенно `lb-LU`).

## Коды языков

Коды языков — BCP 47 (RFC 5646). В колоде встречаются два вида кодов, правила у них разные:

- **Язык интерфейса и значений** — ключи в `meaning`, `hint`, `note` и в названиях тегов (`tags`): только ISO 639-1, то есть `tg`, `ru`, `en`. Не использовать `tj`, `tgk`, `tg-TJ` и т. п. Ключ не из этого списка валидатор принимает с предупреждением, а приложение такой текст не показывает; если в поле нет ни одного из `tg`/`ru`/`en` — это ошибка.
- **Изучаемый язык колоды** — поле `language`, с регионом (`fr-FR`): он задаёт локаль распознавания речи и озвучки.

Таджикские термины и коды — `docs/GLOSSARY_TG.md`, раздел «Коды языков».

## Проверка

Валидатор собирает **все** ошибки сразу и пишет их по-русски, с номером и id записи, например:

```
ОШИБКА: Запись 7 (id «le-nom»): IPA пишется без скобок [ ] и косых / / — приложение добавит их само. Сейчас: «[lə nɔ̃]».
ОШИБКА: Запись 3 (id «das-haus»): в языке «fr» нет рода «n» (средний). Допустимо: m, f.
ОШИБКА: Язык «lb-LU» пока не поддерживается приложением. Поддерживаются: fr.
Предупреждение: Значение на ru есть не у всех записей: не хватает у 3 из 30. Для них приложение покажет другой язык.
```

**Ошибки** (колода не принимается): неверный JSON; нет `deck.json` или он в папке; не тот `format`; неподдерживаемая `version`; нет обязательного поля или у него не тот тип; `revision` не целое от 1; `language` не код BCP-47 или язык не поддерживается; пустой текст; HTML в тексте; неправильный id; одинаковые id записей; неизвестный язык в `meaning`, `hint`, `note` или в названии тега; `tags` колоды не словарь; код тега не по правилам id; неизвестный или повторённый навык; `gender` или `form.gender` не `m`/`f`/`n` или рода нет в языке колоды; `form` не объект или пустой; `form.determiner` не `definite`/`indefinite`; `form.number` не `singular`/`plural`; старое поле `determiner` вне `form` (с подсказкой, как перенести); путь аудио не в `audio/`, с `\` или `..`, расширение не `mp3`/`wav`; аудиофайла нет в архиве (с подсказкой, если не совпадает только регистр букв); старое имя поля `fr` вместо `text`.

**Предупреждения** (колода принимается): проверки содержания Р28 (`src/core/deckContent.ts`) — одинаковое значение у двух записей без различающих `form` / `hint`; слово с тегом `word` и артиклем без `form.determiner`; существительное на «l'» без пары с неопределённым артиклем; существительное с `form.determiner` без `write`; формы, различающиеся только окончанием рода, без `form.gender`; подлежащее il / elle / ils / elles и число un / une без `form.gender`; грамматика текстом в meaning / hint («(м.)», «(мард)»…); `listen` без `audio`; tu / vous без «(informal)» / «(formal)» в en-значении; отклонённое глоссарием слово в `tg`-тексте (таблица в `GLOSSARY_TG.md`, сейчас «артикл»); нет IPA; `form.determiner` без `gender`; «(» или «/» в `text`; неизвестное поле внутри `form`; неизвестное поле (будет пропущено); ключ языка не из `tg`/`ru`/`en` в `meaning`, `hint`, `note`, названии тега (текст не будет показан); одинаковый текст у двух записей; один аудиофайл у двух записей; повторённый тег; тег без описания в словаре `tags`; описанный, но неиспользуемый тег; поля `title` и `description` (название теперь из имени файла); значение на каком-то языке есть не у всех записей; пробелы в начале или конце текста; аудиофайл не используется; лишние файлы в архиве; архив больше 20 МБ.

Проверить колоду на компьютере до загрузки:

```bash
npm run deck:check -- путь/к/колоде.zip
```

## Как собрать архив

Заархивировать **содержимое** папки (файл `deck.json` и папку `audio`), а не саму папку. В Windows: выделить `deck.json` и `audio` → правая кнопка → «Сжать в ZIP-файл».

## Изменения формата

Несовместимые изменения повышают `version`. Новые необязательные поля могут появиться без смены версии: старое приложение их пропустит с предупреждением.
