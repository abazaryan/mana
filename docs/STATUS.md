Edge: распознавание на устройстве — с версии 150, для части языков. **Проверено во встроенном браузере приложения Claude на Windows (Chromium):** API есть (`SpeechRecognitionPhrase`, `available`), французского пакета на устройстве нет, облачный распознаватель сразу ответил `phrases-not-supported` — приложение записало код, повторило попытку без подсказок и запомнило отказ. Ядро, сверка, оценка и журнал при этом не меняются.

Проверено во встроенном браузере (ноутбук, ширина телефона, ответы текстом): шаги знакомства; ✓ одной строкой для «le nom», «parlé» (≈ приглушённо), «21» (без ≈); блоки с ⌨ и зелёным исправлением для неверного ответа; пояснение по нажатию на блок; переключатель подсказок, состояние пакета, запоминание отказа и сброс переключателем. **Раскраска** (Р22.9): блоки по словам, сверху ответ (услышанное), снизу эталон; блок переносится целиком. Под блоками — подпись строк и легенда только присутствующих статусов. «Повторите вслух» — живая подсветка слов по промежуточным результатам (`liveHeard`), итог — по окончательному.

**Сессия** (`src/core/session.ts`, `buildSession`): просроченные `speak` (старые первыми), затем новые по порядку колоды; показ: знакомства → просроченные → вспоминания (Р22.4). ## Известные проблемы

- **Разговорные варианты получают «Снова».** Сверка требует точно эталонную фразу: «ça coûte combien» вместо «Combien ça coûte ?» даёт 33 %. Решение принято: каждая формулировка — отдельная запись.
- **«à» и «au» считаются разными словами.** «J'habite au Luxembourg» получает штраф. Это ожидаемо для сверки по словам.
- **Числа.** Распознаватель, скорее всего, вернёт цифры вместо слов («1» вместо «un»); пока это засчитается как ошибка (предположение, не проверено на колоде с числами). Исправление запланировано на этап 4 (сверка по звучанию, Р5).
- **Задержка включения микрофона 5–12 с** (этап 1) **на телефоне не воспроизводится**: 15.10.2026 — 60–130 мс. Раньше: иногда достигала 5–12 с (4 раза из 28), после чего пользователь нажимал «Повторить». Причину журнал не показывает, потому что ошибка неудачной попытки не записывается. Пользователь говорит, что не заметил случаев, когда говорил раньше включения. Решение: добавить запись ошибки в журнал, если проблема повторится.
- **Журнал прототипа не перенесён:** у приложения новый адрес.
- Встроенный голос браузера пользователю не нравится. Он остаётся запасным вариантом, пока нет аудио из колоды; отключается в Настройках.
- Журнал прототипа хранится в localStorage, последние 300 записей. Резервной копии нет; в новую базу он не переносится (решение пользователя).
- Сообщения валидатора колоды — только по-русски (они для автора колоды), даже при таджикском или английском интерфейсе. Подпись над ними на языке интерфейса объясняет это.
- Восстановление журнала из файла другой установки, если здесь уже есть свои ответы, отказывается: объединение журналов двух установок — этап 6 (синхронизация). В пустую установку файл восстанавливается полностью.
- Удаления колоды пока нет.
- Если значения на выбранном языке нет, экран колоды показывает другой имеющийся язык (порядок: tg, ru, en) с пометкой его кода (например, «TG»); раньше подмена была молчаливой.

- **Этап 4.2, предположения и ограничения.** Микрофон на карточке `speak` включается сам после нажатия «Дальше» (Chrome требует жест пользователя; если не включится — кнопка «Повторить»). На знакомстве микрофон включается кнопкой, чтобы распознаватель не услышал аудио колоды. Время, дроби и проценты цифрами не распознаются. Слово, записанное через элизию и без неё по-разному («l' ami» и «l'ami»), сверяется одинаково, но «c'est» против «sait» — разное число слов, это «Снова». Если сменить вкладку посреди карточки, часы латентности стоят. Правило «Легко» для `speak` берёт число слов N (элизия вместе со словом), а не прежний `countWords` (элизия отдельно) — порог «быстро» для фраз с элизией чуть строже.
- **Перезагрузка страницы посреди порции** собирает порцию заново: сделанные ответы и знакомства уже в журнале, лишних новых не будет.

- **Короткие слова-числа** («un», «deux», «trois») распознаватель Chrome на Android возвращает пустыми; сверка не запускается. Пробуем подсказки распознавателю (эксперимент); если не поможет — набор текстом (после трёх неудач поле открывается само).
- **На Android одна альтернатива** распознавания: выбор лучшей из нескольких на телефоне пока не работает.

- **Дни в ts-fsrs — по UTC** (граница 01:00–02:00 по Люксембургу), а сутки приложения — с 04:00 местного времени: ответы около полуночи UTC ts-fsrs может отнести к разным дням. Не меняем; решаем на этапе 4.4 (Р25 п. 11).
- **Порция растёт при «Снова»**: каждое «Снова» (если до конца порции ≥ 3 карточек) добавляет возврат, «X из N» увеличивается.
- **Латентность `write` без нажатий клавиш**: если ответ вставлен целиком (например, подсказкой Gboard) и `keydown` не пришёл, латентность — `null`, «Легко» не предлагается.
