### Чем это отличается от прежнего плана

- **APKG в приложении не поддерживается**; вместо него свой формат колоды (Р2). JSZip остаётся, sql.js не нужен.
- **Три навыка** (`listen`, `speak`, `write`) с отдельным состоянием FSRS и знакомство без оценки (Р3).
- **Правило оценки**: оценку определяет правильность, а не время; время пишется в журнал (Р4). Пороги по времени из этапа 1 в новой версии не используются для оценки.
- **Сверка голоса по звучанию**, орфография только в `write` (Р5). Приравнивание цифр к словам входит сюда.
- **Интерфейс на трёх языках** (таджикский, русский, английский), язык значений отдельно (Р8).
- **Аккаунты, синхронизация и бэкенд** теперь в плане (Р9–Р11); раньше синхронизация была открытым вопросом.
- Прежнее решение «один правильный ответ на карточку» сохранено (Р3).
- **Несколько изучаемых языков** (Р13): язык задаётся колодой, всё языковое — в языковом пакете; сейчас только французский.
- **Форма ответа** (Р16): вместо печатных конвенций (`ravi(e)`) — отдельные записи с подсказкой `form` (определённость, род, число).

## Этап 4.2: что сделано

Задача и решения — Р22 (план подтверждён с правками 14.10.2026).

**Сверка по звучанию** (`src/core/spoken.ts` — алгоритм; `src/core/frenchSpoken.ts` — данные французского пакета, подключены в `languages.ts` как `spoken`):

- Нормализация: регистр, виды апострофов, дефис = пробел для сравнения, пунктуация, œ → oe; элизия отделяется (`l'ami` → `l'` + `ami`); диакритика сохраняется. M. / Mme / Mlle раскрываются.
- Цифры → слова 0–999 999 по правилам fr-FR (21 → vingt et un, 80 → quatre-vingts, 1 000 → mille), порядковые 1er / 1re / 2e. «1» = только «un».
- Правила омофонов З1–З8 (только явные; всё остальное — другое слово): З1 -é/-ée/-és/-ées/-er/-ez; З2 -ais/-ait/-aient; З3 немое -e/-es; З4 -ent у глагола после ils/elles; З5 немое -s/-x (не перед гласной — связывание); З6 немое -e после гласной; З7 -el/-elle; З8 пары (a/à, ou/où, la/là, du/dû, sur/sûr, ces/ses, ce/se, c'/s', on/ont, son/sont, es/est, peu/peux/peut, veux/veut, vingt/vin/vain, cent/sans/sang). Цифры против слов помечаются правилом «Ч».
- Исключения — закрытыми списками в данных пакета, тест на каждое слово:
  - **З1, -er читается [ɛʁ] (54 слова):** amer, blazer, boxer, bulldozer, bunker, cancer, charter, cher, cluster, cocker, container, cuiller, dealer, docker, enfer, esther, éther, fer, fier, freezer, gangster, geyser, hacker, hamster, hier, hiver, holster, joker, jupiter, kaiser, laser, leader, lucifer, magister, master, mer, mixer, munster, pater, poker, poster, ranger, reporter, revolver, rocker, scooter, speaker, spencer, starter, super, sweater, tender, thriller, ver.
  - **З5/З6, конечное s/x звучит (54 слова):** albatros, anus, as, atlas, autobus, bis, blocus, bonus, box, bus, cactus, campus, cassis, consensus, cosmos, dix, express, fax, fils, hélas, humus, index, jadis, latex, lis, lotus, lynx, maïs, mars, moeurs, oasis, os, ours, papyrus, pathos, plus, processus, relax, rhinocéros, sens, silex, sinus, six, sphinx, stimulus, stress, tennis, terminus, thermos, thorax, tous, tournevis, virus, vis.
- Выравнивание по словам: совпадение 0, пропуск и лишнее 1, другое слово 2 (так сохраняется максимум совпадений); при равенстве слова сопоставляются как можно раньше («très très bien» ← «très bien»: не сказано второе «très»).
- Вердикт (Р22.2): N — слов эталона, E — непрозвучавших, лишние не входят, euh/heu/hum не учитываются. Порог 0,25 — константа `ALMOST_UNSAID_SHARE`. Лучшая альтернатива распознавателя — по вердикту, затем по E, затем по числу лишних, затем по порядку распознавателя.

**Раскраска** (Р22.9): блоки по словам, сверху ответ (услышанное), снизу эталон; блок переносится целиком. Набранный ответ — посимвольно (`checkTyped` и `charBlocks` в `src/core/evaluate.ts`): клетки строит тот же шаг каскада, что вынес вердикт, на той же нормализации; статусы верно / ошибка / пропущено / лишнее / только диакритика. Голос и текст в `speak` — по словам (`spokenBlocks`): верно / по звучанию (≈ и что услышано) / распознано другое слово / не сказано / лишнее; для ответа текстом подпись «другое слово». Второй признак помимо цвета: ≈, волнистое подчёркивание, пунктирная пустая клетка, зачёркивание, точечное подчёркивание. Цифры показываются один раз над словами («21» над «vingt et un»). Под блоками — подпись строк и легенда только присутствующих статусов. «Повторите вслух» — живая подсветка слов по промежуточным результатам (`liveHeard`), итог — по окончательному.

**Микрофон и латентность** (`src/core/voice.ts`, `VoiceCapture`): события `start`, `audiostart` (микрофон готов), `speechstart` (начало речи; если нет — первый результат, источник пишется в журнал), `result` (с уверенностью), `nomatch`, `error`, `end`. `soundstart` не используется. Латентность = начало речи − max(показ карточки, микрофон готов), только видимое время, больше 120 с — неизвестно. Задержка микрофона — от `start()` до готовности. Сторож 5 с (`watchdog`). Все ошибки за карточку — в журнал. `src/platform/speech.ts` теперь передаёт `audiostart`, `nomatch`, уверенность и полный текст для подсветки (прототип работает как раньше).

**Сессия** (`src/core/session.ts`, `buildSession`): просроченные `speak` (старые первыми), затем новые по порядку колоды; показ: знакомства → просроченные → вспоминания (Р22.4). Лимит новых — по журналу за местные сутки с границей 04:00 (`dayStart`), по всем колодам, скрытые записи считаются. Порция 15 (знакомства не в счёт). Знакомство без ответа — вспоминание без нового знакомства. Записи без `speak` ждут 4.3. Причина, почему нет новых: нет материала / лимит / порцию заняли повторения. «Ещё порция» собирает сессию заново.

**Оценка и правка** (`src/core/review.ts`): вердикт → оценка (Р4), «Легко» по окончательной оценке предыдущего ответа; понижать свободно; с «Снова» — только «Меня неправильно распознали» (только голос) → «Хорошо»; «Снова» при ответе текстом и «Не знаю» не повышаются; остальные повышения пишутся как `raised`.

**Экраны**: кнопка «Заниматься» на экране колоды → `#/study/<колода>`. Знакомство: текст, IPA, значение, род, форма, `hint`, `note`, аудио само (нет аудио — встроенный голос) → «Повторите вслух» (кнопка «Говорить», пропустить можно) → «Напишите по образцу» у записей с `write` → «Дальше». `speak`: значение, форма, `hint`; микрофон включается сам; «Повторить», «Написать», «Не знаю»; после ответа — текст, IPA, `note`, раскраска, «Услышано», аудио само, предложенная оценка, 4 кнопки, «Меня неправильно распознали», «Дальше». Итог порции — счётчики по оценкам и «Ещё порция». В Настройках — «Новых записей в день» (5 / 10 / 15 / 20).

**Журнал** — новые необязательные поля (схема Dexie не менялась, миграции нет; `docs/DATA_MODEL.md`): `confidences`, `altIndex`, `latencySource`, `recognitionErrors`, `wordCount` (N), `unsaid` (E), `extraWords`, `soundRules`; у знакомства — `echo` и `copy`.

**Строки**: около 70 новых строк tg/ru/en; новые таджикские термины — `docs/GLOSSARY_TG.md`, раздел «Занятия» (утверждённые 14.10.2026 и отмеченные «на проверку»). `docs/I18N_TG.md` перегенерирован.

**Тестовая колода**: `npm run deck:test-speak` → `decks/test-speak.zip` (12 записей: артикли с подсказкой формы, омофоны, числа, фраза из 7 слов, элизия, повтор слова; без аудио — звучит встроенный голос). Проходит `npm run deck:check`.

Проверено во встроенном браузере приложения Claude на ноутбуке (локальный сервер, ширина телефона): импорт тестовой колоды; «Заниматься» → 10 карточек (5 знакомств + 5 вспоминаний); знакомство, ошибка доступа к микрофону показана («Нет доступа к микрофону»), «Пропустить», «Напишите по образцу» с раскраской (лишняя буква, диакритика); `speak`: эталона нет в странице до ответа; ответы текстом — «les nom» при подсказке формы → «Снова» без возможности повысить; «parlez» → «Хорошо» по звучанию (З1); «21» → верно (Ч); «il parle français» для «ils parlent français» → верно (З4, З5); фраза из 7 слов без «avec» → «Трудно»; итог порции; повторная сборка → «лимит на сегодня»; записи журнала со всеми новыми полями; тёмная тема. ## Этап 3: что сделано

Источник: LivreVivant, коммит `503f4af` (отчёт `reference/livrevivant-report.md`; копии исходников — в `reference/lv/`, не публикуются). Перенесена только чистая логика; везде добавлено «Ported from LivreVivant …» в комментарии модуля.

- `src/core/evaluate.ts` — каскад проверки набранного ответа (навык `write`, Р5): свёртка (регистр, пробелы, апострофы, неразрывные пробелы, запятая, точка и многоточие в конце, типографские пробелы) → пропущенный артикль → только диакритика → опечатка (Дамерау, не больше ⌊длина/6⌋ и не больше 3 правок; у слов до 5 букв допуска нет). Вердикт `correct` / `almost` / `incorrect`, тип ошибки `article` / `diacritic` / `typo`, подсказка о типографском пробеле.
- `src/core/printConventions.ts` — раскрытие печатных конвенций (`ravi(e)`, `A ? / B ?`, `le/la voisin(e)`), `mirrorGloss`, `splitByMeaning`, `foldText`, `lexemeKey`. Без `splitAnnotationSynonyms` и списка синонимов учебника.
- Языковые правила вынесены в языковой пакет (Р13): `WritingRules` в `src/core/languages.ts` — типографские пробелы, артикли, допуск опечаток, артикли для `le/la`, пунктуация без пробела перед ней. Реализован французский.
- `src/core/rating.ts` — вердикт → оценка (`correct` → «Хорошо», `almost` → «Трудно», `incorrect` → «Снова») и «Легко» по новому пункту Р4: верный и быстрый ответ, если предыдущий по той же паре тоже верный и быстрый; быстрый ≤ 2,5 с + 0,3 с на слово сверх четырёх. Причина оценки — кодом, переводит интерфейс.
- `src/core/scheduler.ts` — обвязка ts-fsrs 5.4.1: планировщик без «fuzz» (сроки детерминированы), перевод состояния карточки туда и обратно, применение одного повтора без записи в базу (`applyReview`) и снимок для журнала (состояние **до** повтора, латентность, тип ошибки). ## Известные проблемы

- **Разговорные варианты получают «Снова».** Сверка требует точно эталонную фразу: «ça coûte combien» вместо «Combien ça coûte ?» даёт 33 %. Решение принято: каждая формулировка — отдельная запись.
- **«à» и «au» считаются разными словами.** «J'habite au Luxembourg» получает штраф. Это ожидаемо для сверки по словам.
- **Числа.** Распознаватель, скорее всего, вернёт цифры вместо слов («1» вместо «un»); пока это засчитается как ошибка (предположение, не проверено на колоде с числами). Исправление запланировано на этап 4 (сверка по звучанию, Р5).
- **Задержка включения микрофона** иногда достигала 5–12 с (4 раза из 28), после чего пользователь нажимал «Повторить». Причину журнал не показывает, потому что ошибка неудачной попытки не записывается. Пользователь говорит, что не заметил случаев, когда говорил раньше включения. Решение: добавить запись ошибки в журнал, если проблема повторится.
- **Журнал прототипа не перенесён:** у приложения новый адрес.
- Встроенный голос браузера пользователю не нравится. Он остаётся запасным вариантом, пока нет аудио из колоды; отключается в Настройках.
- Журнал прототипа хранится в localStorage, последние 300 записей. Резервной копии нет; в новую базу он не переносится (решение пользователя).
- Сообщения валидатора колоды — только по-русски (они для автора колоды), даже при таджикском или английском интерфейсе. Подпись над ними на языке интерфейса объясняет это.
- Восстановление журнала из файла другой установки, если здесь уже есть свои ответы, отказывается: объединение журналов двух установок — этап 6 (синхронизация). В пустую установку файл восстанавливается полностью.
- Удаления колоды пока нет.
- Если значения на выбранном языке нет, экран колоды показывает другой имеющийся язык (порядок: tg, ru, en) с пометкой его кода (например, «TG»); раньше подмена была молчаливой.

- **Этап 4.2, предположения и ограничения.** Микрофон на карточке `speak` включается сам после нажатия «Дальше» (Chrome требует жест пользователя; если не включится — кнопка «Повторить»). На знакомстве микрофон включается кнопкой, чтобы распознаватель не услышал аудио колоды. Время, дроби и проценты цифрами не распознаются. Слово, записанное через элизию и без неё по-разному («l' ami» и «l'ami»), сверяется одинаково, но «c'est» против «sait» — разное число слов, это «Снова». Если сменить вкладку посреди карточки, часы латентности стоят. Правило «Легко» для `speak` берёт число слов N (элизия вместе со словом), а не прежний `countWords` (элизия отдельно) — порог «быстро» для фраз с элизией чуть строже.
- **Перезагрузка страницы посреди порции** собирает порцию заново: сделанные ответы и знакомства уже в журнале, лишних новых не будет.
