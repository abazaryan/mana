# Инструкция для ИИ, который готовит колоды «Слуха»

Как пользоваться: скопируйте текст из блока ниже в чат с ИИ (Claude, Gemini и т. п.), в конце допишите задание — тему, список слов или текст урока. ИИ вернёт `deck.json` и список фраз для озвучки. Озвучку вы делаете сами (Gemini TTS), затем собираете ZIP и проверяете его командой `npm run deck:check -- колода.zip` (см. `docs/DECK_FORMAT.md`).

---

```text
Ты готовишь колоду для приложения «Слух» — карточки для изучения французского языка с ответом голосом. Ученик видит значение на родном языке и говорит или пишет по-французски; или слышит фразу и повторяет её. Уровень учеников — A1–A2, если в задании не сказано иное.

ЧТО ВЕРНУТЬ
1. Файл deck.json — один блок ```json без комментариев.
2. Список для озвучки — таблица «файл | текст для озвучки» по всем записям, в том же порядке.
Больше ничего не добавляй, кроме коротких замечаний о спорных местах (если есть) после таблицы.

ФОРМАТ deck.json (строго, лишних полей не добавлять)
{
  "format": "sluh-deck",
  "version": 1,
  "id": "<id колоды>",
  "title": "<название колоды>",
  "entries": [
    {
      "id": "le-nom",
      "fr": "le nom",
      "ipa": "lə nɔ̃",
      "meaning": { "tg": "насаб", "ru": "фамилия", "en": "surname" },
      "audio": "audio/le-nom.wav",
      "gender": "m",
      "skills": ["listen", "speak", "write"]
    }
  ]
}

ПОЛЯ
- id (колоды и записи): строчные латинские буквы, цифры и дефис, до 64 символов. Для записи — из французского текста: без акцентов, пробелы и апострофы → дефис ("je m'appelle" → "je-m-appelle", "la nationalité" → "la-nationalite"). Все id записей разные. Если тебе дали прежнюю версию колоды, id существующих записей НЕ МЕНЯЙ, даже если исправляешь текст.
- fr: французский текст — единственный правильный ответ. Обычная французская орфография и пунктуация, апостроф прямой ('), без HTML. Предложения — с заглавной буквы и точкой; отдельные слова — со строчной и без точки.
- ipa: произношение в IPA, без скобок [ ] и косых / /. Связывание отмечай ‿ ("vu‿zɛt"). Французское R — ʁ.
- meaning: значение. Языки — только те, что указаны в задании (из tg, ru, en); если не указаны — tg и ru. Значение у всех записей на одних и тех же языках.
  - tg — таджикский, кириллица, с буквами ғ ӣ қ ӯ ҳ ҷ. Естественный современный таджикский, не дословный перевод.
  - ru — русский; en — английский.
  - Значение должно однозначно вести к ОДНОМУ французскому ответу. Если по-французски можно сказать иначе, уточни значение (например, «здравствуйте (вежливо)»), либо сделай отдельную запись на каждую формулировку.
  - Числа — цифрами: "meaning": { "tg": "5", "ru": "5" }.
- audio: "audio/<id записи>.wav" — у каждой записи.
- gender: только для существительных — "m" или "f". Существительные пиши с артиклем (le/la/un/une). Если артикль не показывает род (l', les), gender особенно важен. У глаголов, фраз, чисел поля gender нет.
- skills: навыки (типы карточек):
  - "listen" — услышать и повторить (произношение) — у всех записей;
  - "speak" — увидеть значение и сказать по-французски — у всех записей;
  - "write" — увидеть значение и написать — у отдельных слов и коротких выражений (до 3–4 слов); у длинных предложений не ставь, если задание не требует.

ПРАВИЛА СОДЕРЖАНИЯ
- Одна запись = одна учебная единица: слово с артиклем, устойчивое выражение или короткое предложение.
- Один правильный ответ на запись. Синонимы и разговорные варианты — отдельные записи с уточнённым значением.
- Повторов нет: одинаковый французский текст не встречается дважды.
- Порядок записей — порядок изучения: сначала слова, потом фразы с этими словами.
- Лексика и грамматика — по уровню; примеры — бытовые, нейтральные.

СПИСОК ДЛЯ ОЗВУЧКИ
- Колонка «файл» — имя без папки: le-nom.wav.
- Колонка «текст» — ровно поле fr.

ПРОВЕРЬ ПЕРЕД ОТВЕТОМ
- JSON корректен: двойные кавычки, нет запятой после последнего элемента, нет комментариев.
- format = "sluh-deck", version = 1.
- Все id по правилам и разные; audio = "audio/" + id + ".wav".
- В ipa нет скобок; в текстах нет HTML.
- У каждого существительного есть gender; у остальных — нет.
- В meaning — одни и те же языки у всех записей.

ЗАДАНИЕ
<тема, список слов или текст урока; языки значений; id и название колоды>
```

---

## Что делать с ответом ИИ

1. Сохранить JSON в файл `deck.json` (кодировка UTF-8).
2. Озвучить фразы из таблицы в Gemini TTS, сохранить файлы под указанными именами в папку `audio/`.
3. Выделить `deck.json` и папку `audio` → «Сжать в ZIP-файл».
4. Проверить: `npm run deck:check -- колода.zip`. Ошибки исправить (можно отдать их тексты обратно ИИ).
