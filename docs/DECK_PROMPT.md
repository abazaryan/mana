# Инструкция для ИИ, который готовит колоды «Слуха»

Как пользоваться: скопируйте текст из блока ниже в чат с ИИ (Claude, Gemini и т. п.), в конце заполните задание — язык, тему, список слов или текст урока. ИИ вернёт `deck.json`, имя ZIP-файла и список фраз для озвучки. Озвучку вы делаете сами (Gemini TTS), затем собираете ZIP и проверяете его командой `npm run deck:check -- колода.zip` (см. `docs/DECK_FORMAT.md`).

Сейчас приложение принимает только французские колоды (`fr-FR`). Колоду на другом языке ИИ сделает, но валидатор её не примет, пока для языка нет пакета.

---

```text
Ты готовишь колоду для приложения «Слух» — карточки для изучения языка с ответом голосом. Ученик видит значение на родном языке и говорит или пишет на изучаемом языке; или слышит фразу и повторяет её. Уровень учеников — A1–A2, если в задании не сказано иное.

ЧТО ВЕРНУТЬ
1. Файл deck.json — один блок ```json без комментариев.
2. Имя ZIP-файла — название колоды, которое увидит ученик (из задания), с расширением .zip.
3. Список для озвучки — таблица «файл | текст для озвучки» по всем записям, в том же порядке.
Больше ничего не добавляй, кроме коротких замечаний о спорных местах (если есть) после таблицы.

ФОРМАТ deck.json (строго, лишних полей не добавлять)
{
  "format": "sluh-deck",
  "version": 1,
  "id": "<id колоды>",
  "revision": 1,
  "language": "fr-FR",
  "tags": {
    "word": { "tg": "вожа", "ru": "слово", "en": "word" },
    "phrase": { "tg": "ибора", "ru": "фраза", "en": "phrase" },
    "number": { "tg": "адад", "ru": "число", "en": "number" }
  },
  "entries": [
    {
      "id": "le-nom",
      "text": "le nom",
      "ipa": "lə nɔ̃",
      "meaning": { "tg": "насаб", "ru": "фамилия", "en": "surname" },
      "audio": "audio/le-nom.mp3",
      "gender": "m",
      "determiner": "definite",
      "tags": ["word"],
      "skills": ["listen", "speak", "write"]
    },
    {
      "id": "un-nom",
      "text": "un nom",
      "ipa": "ɛ̃ nɔ̃",
      "meaning": { "tg": "насаб", "ru": "фамилия", "en": "surname" },
      "audio": "audio/un-nom.mp3",
      "gender": "m",
      "determiner": "indefinite",
      "tags": ["word"],
      "skills": ["listen", "speak", "write"]
    }
  ]
}

ПОЛЯ КОЛОДЫ
- id: строчные латинские буквы, цифры и дефис, до 64 символов.
- revision: 1 для новой колоды. Если тебе дали прежнюю версию колоды — увеличь на 1.
- language: код изучаемого языка BCP-47 из задания (fr-FR, en-GB, de-DE, lb-LU).
- Названия колоды в deck.json НЕТ: название — это имя ZIP-файла (см. «Что вернуть»).
- tags: словарь тегов — код → название на тех же языках, что и значения (см. meaning). Описывай каждый код, который встречается в записях, и только их.

ПОЛЯ ЗАПИСИ
- id: из текста записи: без акцентов, пробелы и апострофы → дефис ("je m'appelle" → "je-m-appelle", "la nationalité" → "la-nationalite"). Все id записей разные. Если тебе дали прежнюю версию колоды, id существующих записей НЕ МЕНЯЙ, даже если исправляешь текст.
- text: текст на изучаемом языке — единственный правильный ответ. Обычная орфография и пунктуация языка, апостроф прямой ('), без HTML. Предложения — с заглавной буквы и точкой; отдельные слова — со строчной и без точки (кроме слов, которые в языке пишутся с заглавной, например немецкие существительные).
- ipa: произношение в IPA, без скобок [ ] и косых / /. Связывание отмечай ‿ ("vu‿zɛt").
- meaning: значение. Языки — только те, что указаны в задании (из tg, ru, en); если не указаны — tg и ru. У всех записей одни и те же языки.
  - tg — таджикский, кириллица, с буквами ғ ӣ қ ӯ ҳ ҷ. Естественный современный таджикский, не дословный перевод.
  - ru — русский; en — английский.
  - Значение должно однозначно вести к ОДНОМУ ответу. Если сказать можно иначе, уточни через hint, либо сделай отдельную запись на каждую формулировку.
  - Числа — цифрами: "meaning": { "tg": "5", "ru": "5" }.
- hint (необязательно): короткая подсказка, которую ученик видит ДО ответа и которая уточняет, какой ответ нужен: { "ru": "вежливо", "tg": "…" }. Не подсказывай сам ответ. Про определённую/неопределённую форму в hint не пиши — для этого есть determiner.
- note (необязательно): пояснение, которое ученик видит ПОСЛЕ ответа: исключение, связывание, разница с похожим словом. Одно-два коротких предложения. Те же языки, что в meaning.
- audio: "audio/<id записи>.<формат>" — у каждой записи; формат — mp3 или wav из задания, по умолчанию mp3.
- gender: только для существительных: "m", "f" или "n" (средний — только в языках, где он есть, например в немецком; во французском — только m и f). Если артикль не показывает род (l', les), gender особенно важен. У глаголов, фраз, чисел поля нет.
- determiner: только для существительных с артиклем: "definite" — определённая форма (fr: le, la, l', les), "indefinite" — неопределённая (fr: un, une, des).
- tags: 1–2 кода тегов на запись. Основные коды — всегда эти: "word" (отдельное слово, в том числе существительное с артиклем), "phrase" (фраза или предложение), "number" (число). Вторым тегом можно добавить тему урока: свой код по правилам id (например "family") с описанием в словаре tags колоды.
- skills: навыки (типы карточек):
  - "listen" — услышать и повторить (произношение) — у всех записей;
  - "speak" — увидеть значение и сказать на изучаемом языке — у всех записей;
  - "write" — увидеть значение и написать — у отдельных слов и коротких выражений (до 3–4 слов); у длинных предложений не ставь, если задание не требует.

СУЩЕСТВИТЕЛЬНЫЕ: ДВЕ ФОРМЫ — ДВЕ ЗАПИСИ
- Каждое существительное давай ДВУМЯ отдельными записями: с определённым артиклем и с неопределённым ("le nom" и "un nom"; "l'adresse" и "une adresse"). meaning у них одинаковое, различаются text, id, ipa, audio и determiner. Ставь их рядом: сначала определённую, потом неопределённую.
- gender у обеих записей один и тот же.
- Если в задании сказано, что нужна только одна форма, — делай одну.
- Существительное без артикля (например "monsieur") — одна запись, без determiner.

ПРАВИЛА СОДЕРЖАНИЯ
- Одна запись = одна учебная единица: слово с артиклем, устойчивое выражение или короткое предложение.
- Один правильный ответ на запись. Синонимы и разговорные варианты — отдельные записи с уточнением в hint.
- Повторов нет: одинаковый текст не встречается дважды.
- Порядок записей — порядок изучения: сначала слова, потом фразы с этими словами.
- Лексика и грамматика — по уровню; примеры — бытовые, нейтральные.

СПИСОК ДЛЯ ОЗВУЧКИ
- Колонка «файл» — имя без папки, как в audio: le-nom.mp3.
- Колонка «текст» — ровно поле text.

ПРОВЕРЬ ПЕРЕД ОТВЕТОМ
- JSON корректен: двойные кавычки, нет запятой после последнего элемента, нет комментариев.
- format = "sluh-deck", version = 1, есть revision и language.
- Все id по правилам и разные; audio = "audio/" + id + "." + формат.
- В ipa нет скобок; в текстах нет HTML.
- У каждого существительного с артиклем есть gender и determiner, и есть вторая запись с другой формой; у остальных записей этих полей нет.
- Род есть в изучаемом языке (во французском нет "n").
- Каждый код тега из записей описан в словаре tags колоды.
- В meaning, hint, note и названиях тегов — одни и те же языки.

ЗАДАНИЕ
Язык: <например, fr-FR>
Языки значений: <например, tg и ru>
Формат аудио: <mp3 или wav; по умолчанию mp3>
id колоды и название (имя ZIP-файла): <например, fr-lesson-02, «Урок 2»>
Содержание: <тема, список слов или текст урока>
```

## Что делать с ответом ИИ

1. Сохранить JSON в файл `deck.json` (кодировка UTF-8).
2. Озвучить фразы из таблицы в Gemini TTS, сохранить файлы под указанными именами в папку `audio/`. MP3 меньше; если Gemini отдаёт WAV, укажите в задании «Формат аудио: wav». Большой архив (больше 20 МБ) валидатор примет с предупреждением.
3. Выделить `deck.json` и папку `audio` → «Сжать в ZIP-файл». Назвать архив именем, которое предложил ИИ: это название колоды в приложении.
4. Проверить: `npm run deck:check -- колода.zip`. Ошибки исправить (можно отдать их тексты обратно ИИ).
