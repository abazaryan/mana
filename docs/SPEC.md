# Спецификация: «Слух»

Решения владельца продукта — в `docs/DECISIONS.md` (источник правды, номера Р1–Р15). При расхождении прав DECISIONS.md.

## Проблема

В Anki нет режима, где отвечаешь голосом, и нужно вручную нажимать одну из четырёх кнопок оценки после каждой карточки. Пользователь (уровень французского A2) хочет тренировать устное воспроизведение и получать оценку автоматически. Изучаемых языков может быть несколько (французский, английский, немецкий, люксембургский и др.); сейчас реализуется французский (Р13).

## Цель

Отдельный продукт (Р1) интервальных повторений, где:
1. Пользователь видит или слышит подсказку и отвечает на изучаемом языке голосом (или текстом, если говорить нельзя).
2. Ответ сверяется с эталоном.
3. Оценка выставляется автоматически; пользователь может поправить её по правилам из Р4.
4. Колоды загружаются в собственном формате (ZIP с `deck.json` и `audio/`), который готовит ИИ по инструкции `docs/DECK_PROMPT.md` (Р2).

## Факты, предположения, открытые вопросы

**Факты**
- Устройства: Android + Chrome (основное), Windows + Edge.
- Оба браузера поддерживают `webkitSpeechRecognition`. Распознавание идёт через облачную службу браузера (Google в Chrome, Microsoft в Edge) и требует интернета.
- Во встроенном окне claude.ai микрофон не запустился.
- Единственный образец урока — `apkg/fr_lesson_01.apkg` (формат `collection.anki2`, WAV 24 кГц моно, 30 заметок). Он один раз конвертируется в новый формат отдельным скриптом (Р2).
- Один правильный ответ на карточку; другая формулировка — отдельная запись (Р3).
- Gboard не отключает подсказки атрибутами поля (проверено пользователем) — отсюда своя клавиатура (Р6).
- Проверено на этапе 1 (07.10.2026, Android Chrome, по HTTPS): микрофон запускается, 28 ответов из 28 распознаны.

**Предположения (нужно проверить)**
- Время до начала речи — полезный сигнал трудности карточки; по решению Р4 оно пишется в журнал всегда, а по журналу проверяется, не занижает ли правило интервалы.
- `inputmode="none"` надёжно скрывает системную клавиатуру на Android — проверить на устройстве.

**Открытые вопросы** (из DECISIONS.md)
- Надёжность скрытия системной клавиатуры на Android.
- Возраст цифрового согласия в Люксембурге — если появится аккаунт несовершеннолетнего.

## Модель данных

- **Колода** — изучаемый язык (BCP-47, Р13), номер редакции, словарь тегов с названиями на языках интерфейса. Название колоды — имя ZIP-файла; прогресс привязан к `id` колоды. Порядок записей — порядок знакомства (Р15).
- **Запись (Unit)** — одна учебная единица. Поля: текст на изучаемом языке (`text`), IPA, значения на нескольких языках (`tg`, `ru`, `en`, любые из них), подсказка до ответа и заметка после (`hint`, `note`), аудио, род `m`/`f`/`n` и форма `definite`/`indefinite` для существительных (Р14), коды тегов, типы карточек.
- **Языковой пакет** — всё, что зависит от изучаемого языка: нормализация, сверка по звучанию, числа, ряд букв клавиатуры, роды (Р13). Сейчас только французский.
- **Навык (Skill)** — тип карточки. Состояние FSRS хранится отдельно для каждой пары Unit × Skill.
- Устойчивые `id` у колоды и записей: повторный импорт исправленной колоды обновляет содержимое и не стирает прогресс.
- Для будущей синхронизации (Р10): UUID, `userId`, журнал повторений только на дополнение; состояние FSRS выводимо из журнала.

## Формат колоды (Р2)

- Полное описание: `docs/DECK_FORMAT.md`; схема `src/core/sluh-deck.schema.json`; валидатор `src/core/deckFormat.ts`.
- ZIP-архив: `deck.json` + папка `audio/` (WAV или MP3; больше 20 МБ — предупреждение). APKG приложение не поддерживает.
- В `deck.json`: `"format": "sluh-deck"`, `"version": 1`, `revision`, `language` (BCP-47).
- Название колоды — имя ZIP-файла без расширения; при импорте новой редакции обновляется по имени нового файла.
- Значение, подсказка, заметка, названия тегов — на нескольких языках интерфейса; какой показывать, выбирает пользователь в настройках (если нужного нет — любой имеющийся).
- Теги: словарь в колоде (код → названия), записи ссылаются на коды; рекомендуемые коды `word`, `phrase`, `number`.
- Определённая и неопределённая формы существительного — разные записи (Р14).
- Новая редакция колоды: пропавшие записи скрываются, прогресс сохраняется; редакция старее установленной — предупреждение (Р15).
- Валидатор с понятными сообщениями об ошибках.
- `docs/DECK_PROMPT.md` — инструкция для ИИ, который генерирует колоды.

## Навыки и знакомство (Р3)

- **Знакомство** — один раз на запись, без оценки в FSRS: текст, IPA, значение, род и форма (если есть), аудио → повторить вслух → один раз написать по образцу.
- **Повторения** — три навыка, у каждого своё состояние FSRS:
  - `listen` — услышать и повторить вслух (произношение);
  - `speak` — увидеть значение и сказать на изучаемом языке (устное вспоминание);
  - `write` — увидеть значение и написать (орфография).
- `listen` почти не проверяет память (эхо) и не влияет на интервалы `speak`.

## Правило оценки (Р4)

- Правильность определяет оценку: неверно → «Снова»; частично (почти) → «Трудно»; верно → «Хорошо»; «Легко» — верный и быстрый ответ, если предыдущий ответ по той же паре (запись × навык) тоже был верным и быстрым; быстрый = не дольше 2,5 с + 0,3 с на каждое слово сверх четырёх (пороги начальные, калибруются по журналу).
- Латентность (время до начала ответа) пишется в журнал всегда; по журналу проверяем, не занижает ли правило интервалы.
- Автоматическая оценка показывается вместе с четырьмя кнопками; «Дальше» принимает её одним касанием.
- Правка пользователем:
  - понижать — свободно;
  - повысить с «Снова» — только кнопкой «Меня неправильно распознали»: засчитывается «Хорошо», в журнал пишется ошибка распознавания;
  - другие повышения разрешены и записываются в журнал; частые повышения — сигнал менять пороги.
- В FSRS идёт окончательная оценка; в журнале — предложенная, окончательная и причина.

## Сверка ответа (Р5)

- Голосовой ответ сверяется по звучанию (правила — в языковом пакете, Р13; примеры — французские): омофоны засчитываются (`parle`/`parlent`, `-é`/`-er`/`-ez`, `ces`/`ses`); цифры приравниваются к словам («1» = «un»).
- Орфография проверяется только в навыке `write`, каскадом из LivreVivant.

## Своя клавиатура (Р6, только телефон)

- QWERTY и отдельный ряд букв изучаемого языка из языкового пакета; для французского: é è ê ë à â ç î ï ô û ù ü œ æ, апостроф, дефис. Системная клавиатура скрывается (`inputmode="none"`). На ноутбуке — физическая клавиатура.

## Состав сессии (Р7)

- Число повторений определяет FSRS; пользователь регулирует только новые записи.
- По умолчанию 5 новых в день (вариант — 10), можно увеличить.
- Приложение отслеживает удержание и просроченные повторения при увеличенном объёме и предлагает подходящий; при увеличении показывает, сколько будущих повторений это добавит.

## Языки интерфейса (Р8)

- Таджикский, русский, английский. Таджикские тексты переводит Claude, пользователь проверяет.
- Язык интерфейса и язык значений в колоде настраиваются отдельно.

## Пользователи и данные (Р9)

- Семья и несколько друзей; свой аккаунт у каждого, регистрация только по приглашению.
- Колоды загружает администратор (Pooya) в общую библиотеку; пользователи выбирают из неё; прогресс у каждого свой.
- Минимум по GDPR: уведомление о том, что голос уходит в службу распознавания браузера, и где хранятся данные; удаление аккаунта по запросу; для несовершеннолетнего — согласие родителя.
